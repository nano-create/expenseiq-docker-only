ℹ️ How It Works

Recurring transactions are automatically added on the day you specify each month.

For example: set your rent of ₹15,000 on day 1 → it gets added every 1st of the month automatically.

This saves you from manually entering the same transactions every month.

Common use cases: salary, rent, EMI, Netflix, electricity bill, gym membership.
